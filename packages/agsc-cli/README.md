# agsc-cli

Short alias for [`agentic-system-core`](https://www.npmjs.com/package/agentic-system-core) — the AgenticSystemCore CLI (a Distributed Ontological Agentic Memory engine, reference node of the Agentic Knowledge Web).

```sh
npx agsc-cli --help
```

This package contains no logic: it depends on `agentic-system-core` at a pinned version and forwards to its `agsc` binary. Its version is written by the engine's release workflow. Docs: https://agenticsystemcore.com · Licence: Apache-2.0.
