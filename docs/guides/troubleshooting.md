# Troubleshooting — the codes the guides and demos print

**Summary.** A reference page, not a guide: one row for every code that the
[guides](README.md) and the [demos](https://github.com/andreibesleaga/agentic-system-core/blob/main/docs/DEMOS.md) print or quote, with what
you see, the usual cause and what to do. Look a code up here when a command says no. The
full list of codes, with the rules behind them, is the code registry of the
specification ([§9.4 of spec/09-conformance.md](https://github.com/andreibesleaga/agentic-system-core/blob/main/spec/09-conformance.md));
`tests/docs/guides.test.js` checks that every code the guides print, and every code the
guides and demos quote, has a row here.

**Read after:** [the guides](README.md).

---

## Reading a finding

Every finding is one line: its severity, its code, a sentence that names the cause and
the rule, and, when the finding is about a file, the file and line after a dash:

```text
error: AGSC-E310 body reference "salting.md" resolves to nothing inside the Bundle (AGSC-03-11) — content/concepts/brewing.md:15
```

An **error** stops the command: nothing is written, and the exit code is 1. A
**warning** (`warn:`) is advice; the command goes on and still passes. Exit code 2 means
the command itself was wrong (an unknown verb or flag, a missing argument, a bad
setting), so nothing was checked. The checker `validate-wellknown` prints the same codes
after the document's name, for example `…/knowledge-linkset:1:1 error AGSC-E201 …`. With
`--json`, every command prints the same findings as JSON objects instead.

## The codes

| Code | What you see | Cause | What to do |
|---|---|---|---|
| `AGSC-E001` | `unknown verb "help"`; `run executed nothing: …`; `refresh --agent` without `--dry-run` refused; `compose --narrate …: this distribution ships no model adapter` | a verb the engine does not have, or a form of a verb this engine does not ship (running steps needs an isolating runner, an agent lane's live run and a narration of a brief are made by an agent outside the engine) | `agsc --help` lists the sixteen verbs and `agsc <verb> --help` the flags of one; for `run` and `refresh`, use `--dry-run`; for `compose`, drop `--narrate`: the brief is written without it |
| `AGSC-E002` | `unknown option '--…'` | a flag the verb does not take, or an extra argument | `agsc <verb> --help` |
| `AGSC-E003` | `refresh requires --agent <name>`; `compose --narrate <agent> needs --brief`; from the tool server, `an episode needs the instant it started` (the member `at`) | an argument the command or the tool call needs is missing | add the argument the message names |
| `AGSC-E004` | `environment variable AGSC_… is not a configuration name this engine knows; unset it`; `AGSC_… in the .env file …; remove that line`; an unknown key of `agsc.config.json` | a variable or key whose name the engine does not know; a name reserved to a later version (such as `build.feed`) is refused the same way | `unset` the variable (`env` lists them; their names start with `AGSC_`), remove the `.env` line, or remove the key; nothing is written until it is gone |
| `AGSC-E201` | `relation …: digest does not match the bytes of https://…`; `link context members are not ordered …`; a value of the wrong type | a file differs from the one the discovery document names (a host rewrote it, or another build was uploaded), or a file breaks the shape the rules give it | upload the checked build again, unchanged, and turn off host features that rewrite pages; for a file you wrote, fix it at the place named |
| `AGSC-E202` | `no Access-Control-Allow-Origin …`, `no ETag …`, `Cache-Control is …`; a required key or field missing | the host sent a response without a header a node needs, or a required value is missing (such as the `Contact:` line of `security.txt`) | apply the host settings `agsc-host emit <profile>` writes (the [publishing guide](publish.md), step 4); add the missing value |
| `AGSC-E203` | `/task_state: must be equal to one of the allowed values`; `compose --emit crewai: … this distribution ships no rendering for it`; `the program "curl" is not in run.allow[]` | a value outside a closed list: a task state, an export or compose target this engine does not ship, a program a procedure may not run | use one of the listed values; for `compose`, leave out `--emit` or name a plugin; add the program to `run.allow[]` only if you mean it |
| `AGSC-E204` | `the build instant defaulted to 1970-01-01T00:00:00Z …`; a slug, address or date in the wrong form | the build has no instant (no commit and no `SOURCE_DATE_EPOCH`), or a value does not match its pattern | commit once, or `export SOURCE_DATE_EPOCH=$(date +%s)`; fix the value at the place named |
| `AGSC-E206` | `content/procedures/<name>.md already exists with other bytes; an import never writes over an item the Bundle holds` | an import, such as `agsc skills import` of a pack back into its own Bundle, would replace an item the Bundle already holds; at 1.0.0 this happens even for a pack that has not changed | move the item aside, import, then restore by hand what the import does not carry; the [Mode 3 guide](mode-3.md#5-bring-skills-in) gives the steps |
| `AGSC-E207` | `domain_links is stated on a node with no site vocabulary file, so no member names a property and nothing reads it …` (warning); an unknown key of a note or a `SKILL.md` | a key the rules do not know here: `domain_links` on a node whose `agsc.config.json` names no `domain.vocabulary`, a misspelt key, or a key of a later version | name the vocabulary file under `domain`, or remove the key; fix the spelling; a key of a later version is kept as it is |
| `AGSC-E209` | `relation "made-up" is neither a registered name … nor a …/rel#<name> extension URI` | a discovery document or a boundary setting (`federation`, `chunks`, `budget`, `visibility`, …) with a value the rules do not allow; or a statement of a peer's crosswalk that is not `<your concept or lesson> skos:exactMatch\|closeMatch\|broadMatch\|narrowMatch <the peer's IRI>` | use a registered relation name or the extension form; keep the setting inside its bounds; write the crosswalk statement in that form |
| `AGSC-E301` | `Link "implements" target "no-such-item" resolves to no item` | a typed link in a header names an item the Bundle does not hold; at 1.0.0 `build` passes and leaves the link out of the graph, while `lint` and `ci` refuse it | fix the slug, or add the missing item; run `agsc ci` before you publish |
| `AGSC-E305` | `"hydration" has no inbound Link and no clusters[] entry` (warning) | no other note points at this one with a typed link, and no cluster lists it | add a typed link to it in a related note's header (a key such as `related:`; the [data model](https://agenticsystemcore.com/docs/data-model/) lists all fourteen), or list it in a cluster; a link in the text does not count |
| `AGSC-E310` | `body reference "salting.md" resolves to nothing inside the Bundle`; `build` writes nothing | a link in the text to a note or file that does not exist | fix the link at the file and line named, or add the missing note |
| `AGSC-E313` | `<item> uses the irreflexive property … toward itself` (warning, from `export --closure`); `"a" lists itself under "related"` (warning, from `lint`) | a note points at itself, which makes no sense for a property such as `excludes` | remove the note's own slug from that list |
| `AGSC-E317` | `domain link "owns" names no object property of the site vocabulary`; `domain link "controls" is the computed inverse of "controlled-by" and is not authored`; `build` writes nothing | a member of `domain_links` that the site vocabulary does not allow: a relation the file does not define, the inverse the build adds itself, or a kind of `skos:related`, `skos:broader` or `skos:narrower` used on a cluster | use a relation of the file; of a pair declared with `owl:inverseOf`, write only the one the build does not add (the [Mode 1 guide](mode-1.md) says which) |
| `AGSC-E406` | `no PRIVACY.md in the Bundle root …` (warning); a section a page or kind expects is missing | a published page has no text of yours to show, or a note lacks a section its kind lists | add `PRIVACY.md` beside `LICENSE-CONTENT`; add the missing section |
| `AGSC-E408` | `a concept carries no description` (warning) | the note's header has no `description:` | add a one-line `description:` of 40 to 200 characters |
| `AGSC-E412` | `acc and thick on one line would write stroke-width twice …`, `exactly one element must be marked acc (found 0)` or `"rel=friend" names no Link key …`, each naming a line of `content/diagrams/<note>.diagram`; `build` writes nothing | a line of a diagram source is outside its language (AGSC-01-42): an unknown kind of line, a shape outside the canvas or over another, an arrow to a name no earlier line defined, `acc` on no shape or on two, `acc` with `thick`, a `via` that is not pairs of numbers, or a `rel=` that is none of the fourteen relations | change the line the message names; keep `acc` on exactly one shape, and after `rel=` write one of the relations the legend on `/clusters/` lists |
| `AGSC-E413` | `login/SKILL.md: the bytes do not match the SHA-256 the lockfile records …; nothing was installed` | a skill pack was changed after it was locked | leave the installed packs as they are and run `agsc skills` again from the source, which writes the packs and their lockfile together; then install |
| `AGSC-E416` | `a title or alias of concept "scheduler" overlaps one of "planner" after NFC and case folding` (warning) | two published notes of one type have the same title or alias once capitals and accents are folded, so a reader and a tool cannot tell the two names apart | rename one title or alias, or merge the notes |
| `AGSC-E417` | `explainer "thin" has fewer than 2 counted sources …` (warning) | `lint.min_sources` is set, and a pattern, taxonomy, explainer or principle has fewer distinct sources than that; a source that is the address of a note a model wrote does not count | cite more sources in the note's `sources:`, or lower `lint.min_sources` (0 turns the check off) |
| `AGSC-E418` | `domain_type Turbine names no class of the site vocabulary …`; `domain_context payments names no context that domain.contexts declares`; `build` writes nothing | a note's `domain_type` is no class of the file `domain.vocabulary` names, or the node names no such file, or its `domain_context` is no cluster `domain.contexts` declares; or the note is in a context and the class is not under that context's namespace | use a class of the file, add the class to the file, or declare the context in `agsc.config.json`; for a note in a context, define the class under the context's namespace, or move the note out of the context |
| `AGSC-E419` | `the title of concept "account-c" equals the title of "account-a" inside the context billing after NFC and case folding; a term has one meaning inside its context` (warning) | on a node that declares contexts (`domain.contexts`), two published notes of one context, of any type, have the same title once capitals and accents are folded | rename one, or move one to the context where its meaning belongs with `domain_context`; notes in two different contexts may share a title |
| `AGSC-E420` | `<…#Widget> is a subclass of 0 of the six item classes …`; `<…#floats> is not an owl:ObjectProperty that is a sub-property of one of the fourteen link properties …`; `build` writes nothing | the file `domain.vocabulary` names breaks one of the rules of a site vocabulary: each class must sit under exactly one of the six note types, each property under one of the fourteen link types, with no domain or range, both sides of an `owl:inverseOf` relations the file defines, and every term needs a label; or, from `verify` and `ci`, the file `domain.shapes` or `domain.questions` names uses a part of SHACL or SPARQL the engine does not run (including an `ORDER BY` that leaves out a returned variable, or `LIMIT` without one), or a question lacks one of `expected`, `id`, `query` and `question` | fix the term the message names; `node tools/validate-ontology <file>` checks a vocabulary file alone with the same rules; [SHACL-SHAPES.md](https://github.com/andreibesleaga/agentic-system-core/blob/main/docs/SHACL-SHAPES.md) and the [Mode 1 guide](mode-1.md) list what shapes and questions may use |
| `AGSC-E421` | `engine-a breaks the invariant …#EngineControlled on …#controlled-by: Every engine needs a controller.` (an error; a warning for a shape of `sh:Warning` or `sh:Info` severity) | `verify` or `ci` evaluated the shapes of `domain.shapes` over the graph, and a note, or another node of the graph, does not meet one | change the note so it meets the rule, or change the rule; the message names the shape and the shape's own `sh:message` |
| `AGSC-E422` | `the competency question engines ("Which items are engines?") is answered {"rows":[…]}, not the expected {"rows":[…]}` | `verify` or `ci` ran a question of `domain.questions` and the graph gives another answer than its `expected` | if the graph is right, write the answer the message shows into `expected`; if not, change the notes; rows of a `SELECT` without `ORDER BY` may be listed in any order |
| `AGSC-E506` | `site.base was set to the development placeholder http://localhost/ …`; `title was too short and was replaced by the slug`; `index.md is never adopted as an item` (warnings) | the engine chose, normalised or left out a value for you, and says so | read the line; set a real `https:` address in `site.base` before publishing; change any value it chose that you want otherwise |
| `AGSC-E509` | `agent ghost is undeclared or disabled` | an agent lane named on the command line or in a tool call is not declared, or is turned off, in `agsc.config.json` | declare the lane in `agents[]` of `agsc.config.json` with `enabled: true` (the [Mode 5 guide](mode-5.md)), or use a declared one |
| `AGSC-E510` | a model call skipped because a monthly budget is reached (warning; also on the NOW page) | the lane's `budget_usd_month` or the node's `budget.usd_month` is spent | raise the budget, or wait for the next month |
| `AGSC-E511` | `the task "…" is already TASK_STATE_WORKING under …; the first merged claim wins`; `… max_claims is 1` | a claim of a task someone else holds, or more claims than the lane may hold | pick another task, or finish one first |
| `AGSC-E512` | `/warrant: must have required property 'source'`; `/warrant/type: must be equal to one of the allowed values` | a note's `warrant` has no `source` or no `type`, or a type other than `literary`, `user` and `organisational` | give the warrant both members, with one of the three types |
| `AGSC-E603` | `SOURCE_DATE_EPOCH "abc" is not an integer number of seconds` | the variable is set to something other than an integer number of seconds; an empty value counts as unset | `export SOURCE_DATE_EPOCH=$(git log -1 --format=%ct)` or `unset SOURCE_DATE_EPOCH` |
| `AGSC-E901` | `no .well-known/security.txt in the Bundle root …`; `target not found on disk: …`; a file a command needs is missing; from the tool server or a page, `no build instant: the discovery document of a build … is absent or unreadable` for `brief` | a file that must exist does not: the security contact, a file the discovery document lists, `LICENSE-CONTENT` for an export | add the file (the [Mode 0 guide](mode-0.md), step 2, for the security contact); build again before checking; for `brief`, fix what stops `agsc build` and start the tool server again |
| `AGSC-E905` | `scheme not allowed: http:`; `address refused: …` | the checker refused to fetch an address: not `https:`, or a private or loopback address | publish over HTTPS; for your own machine, add `--dev` |
| `AGSC-E906` | `request budget of 500 spent (federation.max_requests, AGSC-11-10(c))` | the checker was asked to fetch more files than its budget; a discovery document that lists thousands of files, or a loop of redirects, spends it | check the document; to allow more on purpose, pass `--max-requests <n>` (1 to 2000) |
| `AGSC-E907` | `HTTP 404 for https://…`; `anchor … is not on the origin the document was retrieved from`; `resolved, not mutual: no rel#peer names …` | a node or one of its files could not be fetched, it names another address in `site.base`, or two peers do not name each other | upload the contents of `www/` to the address in `site.base`; list each node in the other's `peers` (the [Mode 1 guide](mode-1.md)) |

## Not a code

| What you see | Why | What to do |
|---|---|---|
| `agsc: command not found` | the `export PATH=…` line was not run in this shell | run the two `export` lines of [the guides](README.md#before-any-guide) again from the working folder |
| `left as is: <note>.md already has a frontmatter block …` | `init` adopts only notes without a header; a note that already has one is left where it is and not published | the [Mode 0 guide](mode-0.md), step 1 |
| on `/query/`: `The query engine could not start in this browser.` or `The graph could not be loaded (…)` | the host does not send the `/query/*` block of `_headers` (a policy without `'wasm-unsafe-eval'` refuses the engine), sends it joined to the site-wide policy (two policies are both enforced), or serves `web_bg.wasm` with a type other than `application/wasm`; or `/graph.nq` is not served | serve `www/` with the file the engine writes for your host (`agsc-host emit <profile>`, or `_headers` as built on Cloudflare Pages), then open `/query/` again; `agsc-host serve` shows the page working locally |
| `skipped: /feed.xml (reserved to 1.1 …)` and the other `skipped:` lines | routes this build does not write, each with its reason | nothing; they are information |
