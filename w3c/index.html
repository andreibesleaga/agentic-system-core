Agentic Knowledge Vocabulary and Discovery Profile

This report defines agsc, an RDF vocabulary for describing published units of knowledge — concepts, recorded episodes, procedures, lessons, clusters and quality gates — together with their provenance, their typed links and the bundle that publishes them. The vocabulary is aligned to SKOS, PROV-O and Dublin Core Terms, stays inside the OWL 2 RL profile, and is published at the persistent namespace https://w3id.org/agentic-system-core/ns# with content negotiation to Turtle, JSON-LD and RDF/XML.

The report also documents the discovery profile by which a site advertises the knowledge artefacts described with this vocabulary, and the identifier https://w3id.org/agentic-system-core/profile/agentic-knowledge under which that profile is named. The normative definition of the discovery resource itself is [[AGSC-WELLKNOWN-ID]]; this report does not restate it.

This is an early draft. Section content marked TODO is not yet written; nothing in this document is a stable commitment, and the vocabulary's own normative source remains the Turtle file at https://w3id.org/agentic-system-core/ns.

This report describes a vocabulary and a naming convention. Conformance levels for software that publishes, reads or writes bundles described with this vocabulary are defined in section 10 of [[AGSC-SPEC]] (Level 0 Publisher, Level 1 Reader, Level 2 Writer/Exporter, Level 3 Full engine) and are not redefined here.

Namespace, versioning and content negotiation

The namespace IRI of this vocabulary is https://w3id.org/agentic-system-core/ns#; the customary prefix is asc:. Terms use the hash form, so a term IRI is the namespace IRI followed by the term name, for example https://w3id.org/agentic-system-core/ns#Concept.

The ontology document carries owl:versionIRI. Each released version is also published at an immutable versioned path, so that the version IRI resolves: https://w3id.org/agentic-system-core/ns/<major>.<minor>.<patch>, optionally with a SemVer pre-release suffix.

Dereferencing the namespace IRI performs an HTTP 303 See Other redirect to a static representation chosen from the Accept header, following the W3C recipes for publishing RDF vocabularies:

Content negotiation for the namespace IRI
AcceptRepresentation
text/turtlethe ontology in Turtle
application/ld+jsonthe JSON-LD context document
application/rdf+xmlthe ontology in RDF/XML
anything elsethis human-readable term index

Terms are never deleted. A withdrawn term is marked owl:deprecated true and, where a successor exists, carries dcterms:isReplacedBy.

Vocabulary

The vocabulary has 12 classes and 40 properties — 52 terms in all (19 object properties, 21 datatype properties; counts derived by tools/count-artifacts, rc.3 draft 2026-09-16). It stays inside OWL 2 RL. There is deliberately no common superclass for the six authored item types: "item" is a term of the file-format specification, not of the ontology.

Object properties

Six of the nine core link keys reuse SKOS, Dublin Core Terms and PROV. The properties below are the ones this vocabulary defines: three core keys, one computed inverse, the untyped mention edge, the two item-reachability edges, and the five links used for engineering traceability with their computed inverses — nineteen in all (two added at rc.3: asc:hasAttachment and asc:peerOrigin). A property marked computed inverse is never authored by hand.

asc:uses—Soft dependency: the subject draws on the object. A composition warns when a used item is absent. No domain, range or super-property is declared.

The agentic-knowledge discovery profile

A site that publishes knowledge described with this vocabulary advertises it from one well-known resource whose representation is a link set. That link set is identified as following a named profile, and the profile identifier is https://w3id.org/agentic-system-core/profile/agentic-knowledge. Dereferencing the identifier yields the human-readable published specification of the profile.

The normative definition of the resource, its link relation types and its target attributes is [[AGSC-WELLKNOWN-ID]]. This section exists so that a reader arriving from the vocabulary can find the discovery layer, and so that the profile identifier has a stable explanation inside W3C space; it introduces no requirement of its own.
