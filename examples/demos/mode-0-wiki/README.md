# `mode-0-wiki/` — three notes to adopt

Two Markdown notes with no frontmatter (`notes/brewing.md`, `notes/grind-size.md`),
one note that already carries a frontmatter block with a `stale_after` instant that
has passed (`boiling-point.md`), and the `security.txt` a published node needs. The
demo runs `agsc init` in `notes/`, copies the other two files in, and goes on to
lint, build, propose, review and `ci`. See Mode 0 in
[docs/DEMOS.md](https://github.com/andreibesleaga/agentic-system-core/blob/main/docs/DEMOS.md).
