# `mode-1-memory/` — three nodes and one made by hand

`a/`, `b/` and `c/` are the same two-concept Bundle under three bases. `a` and `b`
name each other in `peers[]`; `c` names `a`, and `a` does not name `c`, so the mutual
check fails for that pair. `level-0/` is a node written without the engine — two
Markdown items, `graph.jsonld`, `llms.txt` and a discovery document with no digest —
for the shipped checker to judge at Level 0. The agent demo uses `a`. See Mode 1 and
the agent demo in [docs/DEMOS.md](https://github.com/andreibesleaga/agentic-system-core/blob/main/docs/DEMOS.md).
