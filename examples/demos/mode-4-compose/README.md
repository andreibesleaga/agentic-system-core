# `mode-4-compose/` — a Harness, and the run verb

The two-concept Bundle plus the `login` board, two runnable procedures (`greet`,
whose step is `echo hello`; `fetch`, whose step is `curl`), a run record
(`run1.json`) for `agsc trace`, and a configuration that enables `run` for `echo`
only and caps the month's spend at one dollar. See Mode 4 in
[docs/DEMOS.md](https://github.com/andreibesleaga/agentic-system-core/blob/main/docs/DEMOS.md).
