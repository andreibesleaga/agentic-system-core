# `mode-3-skills/` — procedures that become skills

The two-concept Bundle plus a `login` cluster with one procedure, so `agsc skills`
emits two packs; and `foreign/plain-notes/SKILL.md`, a skill in the Agent Skills
layout with its own licence, for `agsc import --from skills`. See Mode 3 in
[docs/DEMOS.md](https://github.com/andreibesleaga/agentic-system-core/blob/main/docs/DEMOS.md).
