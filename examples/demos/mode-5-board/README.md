# `mode-5-board/` — a board with one agent lane

The two-concept Bundle plus the `login` board (two tasks, one procedure) and a
configuration that declares one agent lane, `worker` (one task at a time, one dollar
a month), its channel `main` and a contribution target. See Mode 5 in
[docs/DEMOS.md](https://github.com/andreibesleaga/agentic-system-core/blob/main/docs/DEMOS.md).
