# `mode-2-project/` — a project's own items

The two-concept Bundle plus a `login` board: a decision (`decide-the-login`), a
specification that implements it (`login-spec`), two tasks (`task-login-tests` is
working and blocked by `task-login-form`), a procedure (`run-the-tests`) and a gate
(`merge-gate`, level L2, three checks, enforced as a status check and a ruleset).
See Mode 2 in [docs/DEMOS.md](https://github.com/andreibesleaga/agentic-system-core/blob/main/docs/DEMOS.md).
