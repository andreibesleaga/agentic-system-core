# `plugins/` — the Claude Code plugin

**Summary.** [`agentic-system-core/`](agentic-system-core/README.md) is a Claude Code plugin that carries the agent skill of [`skills/agentic-system-core/`](../skills/README.md) and nothing else: no hooks, no tool server, no scripts. Its copy of the skill is the same bytes without the passages about the engine's tool server, because a plugin that declares no server may not tell anyone to add one (the rule of Claude's plugin directory). The marketplace file `.claude-plugin/marketplace.json` at the repository root points at this folder, so `claude plugin marketplace add andreibesleaga/agentic-system-core` finds it.

`tests/docs/agent-skill.test.js` lists those passages (`LEFT_OUT`), keeps the two copies equal apart from them, and holds the plugin to its content-only file list, so the plugin folder takes no file beyond that list. After a change to the skill, copy its three files into `agentic-system-core/skills/agentic-system-core/` and make the replacements of that list; the test fails until the copy is exact. The plugin is not part of the npm package.
